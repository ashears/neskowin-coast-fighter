- Transparent WebP or PNG for fighters. Proposal Rock is currently loaded from `fighters/proposal-rock.png`; The Chelan is loaded from `fighters/chelan.png`.
- 320x420 or larger source images with transparent backgrounds
- 1280x720 WebP or JPEG for the arena
