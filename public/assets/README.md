# Neskowin art

The production game imports the arena photographs and fighter art referenced by `src/coast/stage.ts`. Vite includes those files in the build. The other assets are retained as source material for the original game.

`fighters/duck-flag-sprite.png` is the resized display version of the original `fighters/duck-flag.png` photograph, rotated 180° so the lettering is upright. The fighter picker and arena share it.
